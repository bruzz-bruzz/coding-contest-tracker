# Discord Bot for Coding Contest Tracker

## Overview
A Discord bot that retrieves information about upcoming coding contests and shows it to users. Built using discord.js and TypeScript.
![TypeScript](https://img.shields.io/badge/typescript-%23007ACC.svg?style=for-the-badge&logo=typescript&logoColor=white)
## Commands
- `/contests` - Get upcoming contest data and filter them by platform.
- `/help` - Get info on the bot's commands.
- `/about` - Get info on the bot itself.
